# GLrefub website

Website for GLrefub, bathroom renovation around Glasgow.

## Run it locally
Open the folder in VS Code, install the **Live Server** extension, then right-click `index.html` → **Open with Live Server**.

## Files
- `index.html`: page content
- `style.css`: colours, fonts and layout
- `script.js`: WhatsApp quote form and copy buttons
- `images/`: project photos
